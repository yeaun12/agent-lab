\# agent-lab



무료 LLM과 로컬 모델로 직접 만드는 AI 에이전트 실습 저장소.

첫 에이전트는 repo-pilot(코드베이스 Q\&A + GitHub PR 리뷰).



\## 목표

\- LLM 주변 시스템(도구 호출, 메모리, 평가, 가드레일, 배포)을 프레임워크 없이 직접 만들고 수치로 증명한다.

\- 겪은 실패는 FAILURES.md에 기록한다.



\## 현재 진행 단계

\- 0단계 환경 세팅 완료 (이 줄을 진행할 때마다 고친다)



\## 폴더 구조

\- src/agent\_lab/core: 공통 부품 (LLM 래퍼, 재시도, 메모리, 평가)

\- src/agent\_lab/agents/repo\_pilot: 첫 에이전트 전용 부품

\- evals/: 에이전트별 평가 질문

\- docs/: 문서 (providers.md 등)
